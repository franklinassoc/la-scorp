# LA-SCORP
Louisiana Statewide Comprehensive Outdoor Recreation Plan

SCORP is the Statewide Comprehensive Outdoor Recreation Plan which identifies recreational needs and issues existing throughout Louisiana. The document, updated every 5 years, outlines a plan for providing and maintaining recreational facilities and provides key information for determining the award of federal grant funds through the Land and Water Conservation Fund. SCORPs occur nationally, being a requirement of the federal government to create a new or update an existing SCORP in each state every five years.

## Purpose
The purpose of this github repository is to store and host development code and functionality for the website for this 2020 - 2030 Louisiana SCORP. This GitHub repository is developed and maintained by [Franklin Associates](https://franklinassociates.com).
